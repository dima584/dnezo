# Lab 2 REST API

Базовий REST-сервіс, створений за допомогою FastAPI та Poetry для лабораторної роботи №2 (Система контролю версій Git).

## Як запустити

1. Встановіть залежності за допомогою Poetry:
   `python -m poetry install`

2. Запустіть сервер:
   `python -m poetry run uvicorn main:app --reload`
